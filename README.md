# ERP Sales Invoice System
A simple Windows Forms ERP Sales Invoice application built with C#, .NET, Entity Framework Core, and SQL Server.
This project allows creating, editing, deleting, and viewing invoices with customers and items.


# Features

- Add, edit, and delete invoices

- Manage invoice items with quantity and price

- Automatic total calculation

- Edit existing invoices

- Cancel invoice creation

- Validations on customer selection and item quantity


# Technologies

- .NET 6 (Windows Forms)

- C#

- Entity Framework Core

- SQL Server


# How to Use

1. All Invoices Screen

  - View all invoices

  - Edit or delete existing invoices

  - Click New Invoice to create a new one

2. Invoice Screen

  - Select a customer

  - Add items with quantity

  - Click Save to save the invoice

  - Click Cancel to discard changes    

***Notes***

1.Ensure SQL Server is installed and running

2.Make sure ERPDb database exists or create it manually

3.Invoice numbers are automatically generated
